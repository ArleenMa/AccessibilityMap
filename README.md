AccessibilityMap is an interactive map where Chapel Hill, North Carolina community members are able to report areas where accessiblity is a concern, such as construction sites or broken elevators. 

This is a single-page, client-side-only app that runs in the browser. \
    index.html contains the HTML structure and a <script> block containing all the Javascript logic. \
    App.css has the styling for the page layout.\
    Leaflet provides the interactive map and marker functionality.\
    OpenStreetMap supplies the map tile imagery.
